# Pagina-web
Sobre o projeto
Esse site é um blog dedicado ao aprendizado de crochê. Nele, o usuário encontra vídeos demonstrativos e receitas passo a passo divididas por níveis de dificuldade.

Objetivo
O site tem o objetivo de ensinar coisas feitas de crochê de forma prática e acessível, reunindo tutoriais para iniciantes e modelos mais avançados para quem quer praticar.

Funcionalidades
Vídeo de tutorial incorporado para assistir direto na página.
Botão de curtir com contador de interações.
Botão de modo escuro para alterar o fundo da página (Acessibilidade).
Organização dos tutoriais por níveis (Fácil, Intermediário e Difícil).

Justificativa
Esse site foi desenvolvido para organizar ideias e receitas de crochê em um único lugar de maneira simples e agradável, ajudando tanto iniciantes quanto pessoas que já praticam o artesanato a acompanhar os tutoriais facilmente.

Instruções do Site
Início: Apresenta o cabeçalho e um vídeo demonstrativo com botão de curtir.
Navegação: O usuário pode alternar para o modo escuro no botão do topo.
Tutoriais: Abaixo, o leitor pode acompanhar a lista de receitas organizadas em cartões com imagens e o passo a passo de cada carreira.
